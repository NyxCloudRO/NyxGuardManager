# NyxGuard Manager 5.0.17 source overlay

Build this directory with `docker build --build-arg BUILD_REVISION=<source-commit> -t nyxguard-dev:5.0.17 .`. The immutable v5.0.16 runtime base preserves native dependencies, licensing, six languages, twelve themes, schema 49 and VPN Agent 5.0.2. Source changes add seven-duration shared historical aggregation, portable Grafana JSON, compact storage management and a constrained Unix-socket host broker. Public qualification is required before publication.

The official installer and host updater install the broker from the accepted image. Manual deployments can run the included `install-storage-host.py INSTALL_ROOT MANAGER_CONTAINER` as root, after mapping `INSTALL_ROOT/.maintenance/run` read-only at `/run/nyxguard-storage`. It does not grant the application general host-file or additional Docker API access. Inventory/deletion is disabled if the host broker or verified recovery set is unavailable. See [release notes](RELEASE-NOTES.md) and [storage security design](STORAGE-SECURITY.md).
