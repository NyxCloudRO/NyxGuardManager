# NyxGuard Manager 5.0.17 source overlay

Build this directory for local development with `docker build --build-arg BUILD_REVISION=<source-commit> --build-arg APP_VERSION=5.0.17-dev.1 -t nyxguard-dev:5.0.17 .`. The candidate version appears in the frontend, package and API metadata. Omit the version override only when building the stable artifact for release qualification. The immutable v5.0.16 runtime base preserves native binaries, licensing, six languages, twelve themes, schema 49 and VPN Agent 5.0.2. Source changes add seven-duration shared historical aggregation, portable Grafana JSON, compact storage management and a constrained Unix-socket host broker. Pinned trust-store updates remove the compromised emSign G3 root from system and Certbot stores; Node uses the patched system CA bundle. Public qualification is required before publication.

The official installer and host updater install the broker from the accepted image. Manual deployments can run the included `install-storage-host.py INSTALL_ROOT MANAGER_CONTAINER` as root, after mapping `INSTALL_ROOT/.maintenance/run` read-only at `/run/nyxguard-storage`. It does not grant the application general host-file or additional Docker API access. Inventory/deletion is disabled if the host broker is unavailable. Default recovery protection can be explicitly waived with the external VM backup option. See [release notes](RELEASE-NOTES.md) and [storage security design](STORAGE-SECURITY.md).
