# Compatible runtime backports for 5.0.14

These patches apply to the corresponding fully Debian-patched sources: Expat 2.5.0-1+deb12u4, Python 3.11.2-6+deb12u9, libtasn1 4.19.0-2+deb12u1, OpenLDAP 2.5.13+dfsg-5, OpenSSL 3.0.22-1~deb12u1 and gzip 1.12-1. Source and Debian packaging archives are identified in source-input-sha256.json and their Debian source descriptors. No distribution version is disguised as a newer upstream release.

Build in a Debian 12 amd64 toolchain with the qualified application filesystem available at `/work/release-rootfs`. Unpack each source descriptor and apply its Debian patch series before applying the matching patch here. Place source roots under `/work/sources/{expat/expat,python,libtasn1,openldap,openssl,gzip}`. The existing Nginx/OpenResty, glibc, both curl backends, libstdc++ and SQLite security corrections remain prerequisites and must be retained byte-for-byte.

Expat narrow: run buildconf.sh, then configure out of tree with --prefix=/usr --libdir=/usr/lib/x86_64-linux-gnu --enable-shared --disable-static --with-docbook=no, and run make/make check in `/work/build-expat`. The unsigned-short wide library uses CMake in `/work/build-expat-ushort`, EXPAT_CHAR_TYPE=ushort, EXPAT_SHARED_LIBS=ON, EXPAT_BUILD_TOOLS=OFF, EXPAT_BUILD_EXAMPLES=OFF, EXPAT_BUILD_TESTS=OFF, CMAKE_BUILD_TYPE=Release. The old upstream suite does not support ushort; use the focused capacity/salt checks and actual wide-character callbacks in addition to the narrow suite. Preserve libexpat.so.1 and libexpatw.so.1.

Python's XML consumers are built into the Debian interpreter. Use build-python-core.sh and the installed Debian Setup.local to retain every built-in module, the original external module directory and DTrace probes. Preserve the existing standard library, including earlier tarfile fixes. A standalone extension build does not replace these built-in consumers. No whole Python dependency stack upgrade is required.

libtasn1: configure --prefix=/usr --libdir=/usr/lib/x86_64-linux-gnu --disable-static, make and make check, in `/work/build-libtasn1`. OpenLDAP: configure --prefix=/usr --libdir=/usr/lib/x86_64-linux-gnu --enable-shared --disable-static --with-tls=gnutls --with-cyrus-sasl --enable-dynamic --enable-slapd=no --enable-slurpd=no, in `/work/build-openldap`; make depend and make. Only the affected libldap binary is replaced; the installed liblber bytes are retained.

OpenSSL: configure shared --prefix=/usr --openssldir=/usr/lib/ssl --libdir=lib/x86_64-linux-gnu no-idea no-mdc2 no-rc5 no-zlib no-ssl3 enable-unit-test no-ssl3-method enable-rfc3779 enable-cms no-capieng no-rdrand enable-ec_nistp_64_gcc_128 debian-amd64, in `/work/build-openssl`. Run targeted DTLS/TLS verification. Replace libssl.so.3 only; retain the qualified installed libcrypto and provider modules. gzip: configure --prefix=/usr in `/work/build-gzip`, make and make check. Both the original shared-state correction and the follow-up initialization placement are present.

package-runtime.py retains installed payloads and maintainer scripts, replaces only qualified runtime binaries, regenerates md5sums and uses explicit +nyxguard1 backport versions. Four Python package revisions move together to preserve exact-version dependencies. Packaging-only Python payloads remain unchanged. Audit dpkg dependencies after installing the complete batch.

These six component patches are supplemented by the ACL library and pinned file-tool caller corrections in ../acl-callers-20261020/. Final artifact identities and qualification status are recorded in the release manifest.
